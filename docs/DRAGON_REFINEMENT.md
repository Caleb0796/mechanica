# Seismoscope dragon refinement

The dragon heads have a continuous muzzle, arched brows, recessed eyes, swept antler horns, curved whiskers, and distinct open jaws. Subtle vertex colors make raised details and recesses legible against the bronze surface.

The face retains its approved display envelope. The current vessel-following mount extends behind it without rescaling the contact footprint. The fitted collar, neck root, ball cradle, and side lips retain the upstream clearance and containment fixes. Recorded machine data, part transforms, source provenance, and both reconstruction schemes remain unchanged. Sculptural details remain display reconstruction under the existing `tuice` provenance.

Geometry checks cover finite surfaces, normals, fitted bounds, vertex colors, material presentation, source references, seated ball contact, and release clearance for all eight heads in the resolved base specification and both scheme patches. Existing vessel mount and ball containment checks are retained.

The catalog previews are regenerated using `pnpm exec node scripts/render-renders.mjs --slug=seismoscope`. The render pipeline supports a machine filter, waits for the model, operates the current cutaway and exploded controls, and clears interaction overlays before capture.

See `SEISMOSCOPE_EXPLORATION_PR.md` for integration ownership and final validation results.
